# Worklog

This section documents the entire **8-week** professional internship journey (from **August 3, 2026** to **September 25, 2026**). Throughout the internship, I followed a structured and hands-on learning roadmap focused on Amazon Web Services (AWS) cloud computing, progressing from core infrastructure services to designing, managing, observing, and optimizing modern cloud workloads.

The internship roadmap is organized into structured progression stages:
* **Cloud Foundations & Core Infrastructure (Weeks 1 - 3):** Exploring AWS Global Infrastructure, account security baselines with IAM, provisioning EC2 instances, managing object storage with Amazon S3, and designing isolated networking environments with Amazon VPC (Public/Private Subnets, Internet Gateways, and custom Route Tables).
* **Modern Compute & Observability (Weeks 4 - 5):** Exploring Serverless event-driven computing with AWS Lambda; implementing comprehensive infrastructure monitoring and telemetry with Amazon CloudWatch (Metrics, Dashboards, Alarms), automated alerting with Amazon SNS, and operational compliance tracking via AWS CloudTrail.
* **High Availability, Elasticity & Containers (Weeks 6 - 7):** Architecting resilient systems by combining Application Load Balancers (ALB) with Auto Scaling Groups (ASG); mastering Docker containerization, publishing images to Amazon ECR, and orchestrating containerized services on serverless Amazon ECS Fargate.
* **Synthesis & Final Review (Week 8):** Consolidating system architecture aligned with the AWS Well-Architected Framework, executing safe resource decommissioning to eliminate unnecessary costs, and presenting the final internship outcomes to the host organization.
